Understanding Web Development

Web development involves several technologies that work together to create websites and web applications.

The three technologies commonly introduced first are HTML, CSS, and JavaScript.

"Good web development begins with understanding what each technology is responsible for."

1. HTML — Structure

HTML stands for HyperText Markup Language. It provides the structure and meaning of content on a webpage.

What HTML can define

  • Headings
  • Paragraphs
  • Links
  • Images
  • Forms
  • Tables
  • Lists
  • Semantic page sections

Basic HTML Structure

<h1>My Website</h1>

<p>Welcome to my website.</p>

<a href="about.html">Learn More</a>

2. CSS — Presentation

CSS stands for Cascading Style Sheets. It controls how HTML elements appear and how they are positioned on a page.

CSS can control properties such as:

  • Colors
  • Fonts
  • Spacing
  • Sizes
  • Borders
  • Backgrounds
  • Layout
  • Animations
  • Responsive behavior

Common CSS Concepts

Concept Purpose Example
Color Changes the color of content color: blue;
Margin Creates space outside an element margin: 20px;
Padding Creates space inside an element padding: 20px;
Border Creates a visible boundary border: 1px solid;
Display Controls an element's layout behavior display: flex;

3. JavaScript — Behavior

JavaScript is a programming language commonly used to make webpages interactive and dynamic.

Examples of JavaScript functionality

  1. Responding to button clicks
  2. Changing HTML content
  3. Changing CSS styles
  4. Validating forms
  5. Creating interactive menus
  6. Communicating with APIs
  7. Working with data

How HTML, CSS and JavaScript Work Together

HTML

Provides the structure and meaning of the webpage.

CSS

Controls the appearance and layout of the webpage.

JavaScript

Controls behavior and interaction.

4. Backend Development

Backend development focuses on the server-side part of applications.

Important Backend Technologies

Server

A system that receives requests and provides responses or services.

Database

A system used to store, organize, and retrieve data.

API

A defined way for different software systems to communicate with each other.

Web Development Learning Roadmap

  1. HTML

    Learn how webpages are structured.

  2. CSS

    Learn how webpages are styled and arranged.

  3. JavaScript

    Learn how webpages become interactive.

  4. Git and GitHub

    Learn how to manage and collaborate on code.

  5. Backend Development

    Learn servers, APIs, databases, and authentication.

  6. Deployment

    Learn how to make applications available online.
